# Cracker-Barrel-Peg-Game

This is a C++ implementation of a simulation of the Cracker Barrel Peg Game. 

## User Interface

Upon execution, the user is met with a control panel featuring four options:

- `a` - Calculates and prints all the possible solutions to the game
- `h` - Determines the hardest starting configuration for the game by calculating the number of solutions for each one
- `p` - Allows the user to play the game from the default starting configuration by entering the number corresponding to the desired valid move
- `q` - Quits the program

## Compilation and Execution

The code utilitzes a Makefile for compilation. To compile, simply enter the following command from the command line:

```make all```

After compilation, the program can be run using the following command:

```./main```
